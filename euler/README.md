# euler

[Project Euler](https://projecteuler.net) problems solved in Mojo, as practice
with the language. Each file is one problem, with the problem statement copied
into the comments at the top.

## Layout

| Path | Contents |
| --- | --- |
| `e1.mojo` to `e8.mojo` | Solutions to problems 1 through 8 |
| `e9.mojo` to `e20.mojo` | Problem statements for problems 9 through 20 |
| `e0.mojo` | A warm-up exercise (sums of odd or even squares), not a Project Euler problem |
| `bitset.mojo` | A bitset example generated by Copilot, kept for reference |

Several solutions keep earlier attempts in comments with notes on why they were
replaced. `e7.mojo`, for example, records the timing of each approach to
finding the nth prime.

## Usage

Run any file from the `projects/` folder:

```sh
pixi run mojo euler/e1.mojo
```

Each solution prints its answer.
